# 组件与状态速查

遵守 `DESIGN.md`。以下说明真实组件的当前用法；业务结果由应用确认，样板不执行写入。完整尺寸与颜色定义读取 tokens，本表不另设数值来源。

| 组件 | 常态与交互 | 在途、失败与边界 |
| --- | --- | --- |
| Button | 主要提交炭黑；次操作中性；危险动作深莓红；hover 不位移，focus 有描边 | busy 保持宽度并显示动作文字；禁用不能重复触发 |
| Field / Textarea | 可见标签、关联说明；输入表面与页面可辨 | 错误在关联区域说明；失败保留草稿；敏感值不普通回显 |
| Switch | 开启为主题暖红、关闭为中性灰，圆钮右/左同时表达状态；复用公共组件与可见焦点 | 保存中阻止重复操作，失败恢复已确认值；启用来源不等同于实际正在记录 |
| Segmented | 确认状态驱动互斥选择；中性选中和键盘焦点 | 保存中阻止重复操作，失败恢复已确认值 |
| Tabs | 下划线与文字区分当前项；方向键移动焦点，点击/回车激活 | 内容可独立加载，未选面板不接收焦点 |
| Modal / Drawer | 焦点进入内容；Tab 在活动模态内；Esc/关闭返回触发点 | 在途沿用既有关闭锁；长内容滚动，提交与关闭可达 |
| Tooltip / Popover | 鼠标与键盘均可感知；内容靠近触发点 | 不能替代必要标签、失败说明或唯一操作入口 |
| 日期导航 | 日期为唯一月历入口，左箭头更新/右箭头更早；箭头紧邻日期且与日期/星期组合居中；标题区域不可选文字 | 今天禁用左箭头，历史可回今天；月请求未知/失败不删除日期，切换淘汰旧响应，月历关闭返回日期按钮 |
| 日概览 | 白卡容器，双声源共用真实时间；未整理浅绿、已整理绿，均平涂无框；真实缺口局部纹理；轴段与轨道同高、统一2px圆角 | 活跃源区间柔和暖红；当前红线上的HH:MM不能单独证明录音；边缘内收，悬停标签优先 |
| 保存时刻标记 | 重点/笔记/截图为双轨上叠加的绿色细竖线与顶部小旗 | 不增第三轨、不改变音频区间；类型/时间可读、键盘可打开原详情 |
| 记录条目 | 进行中和已完成均为暖白卡片、共用中性hover，无左侧装饰色线；6px节点与时间首行对齐，已留存绿、进行中中性灰；只连接相邻节点 | 仅「正在记录」标签为浅暖红底与深暖红文字/点；注意琥珀、失败深莓红；正常空列表为“暂无有效事件”，刷新不抢位置 |
| CaptureStatus | 兔子姿态、状态文字、对应控制 | 暂停睡眠；未知等待；部分来源/阻断清醒提示；不提前显示成功 |
| Player / Transcript | 紧凑播放器；暖红定位和当前句浅底；自然阅读列 | 原音与转录分别判断可用性；暂停保留定位；离开停止播放 |
| MomentList / 笔记输入 | 按时刻排列；已保存标记绿；原图与 OCR 独立 | OCR 失败不表示图片丢失；保存失败保留文本和时间锚点 |
| People | 整行进入详情；人物与样例来源明确 | 无原音禁用播放；删除确认；切换人物淘汰旧请求 |
| Queue / Statistics | 类型、范围、进度清楚；图表系列与图例对应 | 空值不当零；费用标估算；失败和重试使用真实任务事实 |
| Agent 接入 | MCP / CLI 选择；配置可换行与复制 | 连接未知或失败独立说明；复制成功才反馈 |
| 常驻入口 | 兔子收起、暖黑展开；沿用顶部/悬浮各自操作 | 保存反馈依据结果；不抢主窗；草稿、透明命中和屏幕边缘沿用宿主契约 |

实现复用仓库 `src/Controls.tsx`、`TimelineView.tsx`、`CaptureStatus.tsx`、`DetailDrawer.tsx`、`MomentList.tsx`、`FloatingWidget.tsx` 及相应页面。`preview.html` 展示重建时的真实组件和合成资料；`release/screenshots/` 是历史截图，日期与适用范围见其 README，不能作为当前样式规范。浏览器检查说明 Web 行为，原生入口与安装结果另见仓库交付台账。

平台呈现遵守主规范：macOS 顶部入口、Windows 系统托盘复用持久模式top，悬浮模式不变；Windows 面板四角使用既有26px入口轮廓，悬浮菜单20px。Windows声音来源区分设备准备和实际记录，权限指引对应Windows设置；安全存储文案不依赖macOS钥匙串。mock平台样板不代替原生/DPI/安装验收。
