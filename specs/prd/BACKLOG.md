# 后续版本需求

本文件记录明确不属于当前0.1交付的需求，不是当前PRD的后续开发批次。进入开发前分别收敛范围、技术方案及验收标准，形成独立PRD。

## 下一版本：事件自动摘要与关键结论

- 记录日期：2026-09-22。
- 来源：用户选择本版不做自动摘要，并明确要求「一期需求不要，但记录需求作为下个版本」。
- 目标：在完整文字稿、音频、截图与评论的基础上，为事件提供简短摘要和关键结论，帮助快速浏览历史内容。
- 当前边界：0.1提供标题、完整文字稿、音频和关联截图；自动摘要及关键结论不属于0.1验收条件。
- 后续需确定：输入范围、生成时机、模型及费用、结果来源定位、人工修改/事件重组后的更新、可靠性与验收标准。
- 状态：已记录下一版本需求，尚未进入可开发状态；没有指定版本号、发布日期或供应商。

## 后续平台：Windows

- 首版正式支持 macOS，并在该平台完成全天录音、事件整理、清理与完整 CLI 闭环。Windows 保留为后续平台目标。
- 后续需单独验证双路声音采集、主动截图、本地模型资源消耗、登录/锁屏/睡眠、完整命令行与安装分发，再定义 Windows 的最低系统版本和验收范围。

## 后续能力：主题级自定义处理

- 预留事件形成后的处理扩展点，未来可按主题配置 Prompt、Skill 或其他工作流。
- 本版不提供用户配置或自动摘要/结论；后续需另定触发条件、输入范围、外发授权、结果更新和错误处理。
