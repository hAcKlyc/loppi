# 自动流程统一列表

自动精转作为固定首行，与自定义生成策略共用流程、输入、触发条件和编辑列。每行的编辑按钮打开对应配置弹窗。自动精转的触发条件在弹窗中编辑，应用到原有共享草稿。

## 执行台账

- 契约。复用 `WorkflowSettings`、`Modal`、`SegmentedOptions`、`TagChoices` 和既有配置请求。内置行不支持移除。取消弹窗保留原草稿，应用后更新列表摘要，保存和依赖处理继续由 Core 校验。
- 验收。默认与已配置状态均有内置首行。验证内置和自定义编辑、取消、应用、跨页草稿、依赖定位与补齐，以及窄窗、键盘焦点和原生开发包。
- 基线。 `0f6fadf`。范围为自动流程界面、局部样式及对应回归。
- 验收记录。实现 `3536072` 通过前端构建、lint、18 项定向回归及独立审查。760×600 浏览器验证默认和已配置的列表、两个编辑弹窗、取消及键盘焦点。Apple Silicon 开发包构建通过，原生窗口验证官方首行及弹窗打开、关闭和焦点恢复。
