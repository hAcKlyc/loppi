# 日期切换闪烁与连续动效
## Bug Class Map / 根因
- 用户路径：顶部邻日点击，短暂“暂无记录”、字号位置跳变。
- 同根：日历选日、首次加载、日历请求失败、自动回退、快速切换、稀疏日期窗口。
- App 把月级 recordedDays 和日级 items 一起清空；header 将 unknown 解释为空；同日期 div/button 替换无法连续变化。自动回退后旧请求还继续写 gaps/moments。
- 双路独立调查一致。排除云端处理、录音开关、日历自身月份加载（独立生命周期）。历史数据无迁移。
## Repair Radius
- App 保留同月导航，跨月重置月数据；失败保留已知导航；日期请求按当前选中日期与序号裁决；首次自动跳转后停止旧请求发表，手动选日不自动跳走，同日点击无重载。
- header 始终包含当前选中日（不依赖日内容加载），同 key 同元素；三日窗口在边缘保持最多三项；尺寸/间距/文字位置连续过渡，窄窗不通过 order 跳排；遵循减少动态效果。
- 数据仍按新日期加载，不把上一日内容显示成新日期；不新增缓存/状态owner/后端API/动画依赖，不改详情与录音流程。
## 验证与结束
- 旧版失败的 unknown/empty 日期头回归、边缘日期窗口、实际DOM选择与异步导航检查；前端 typecheck/lint/build 与相关 node tests；独立需求+对抗后架构审查；签名本机构建与日期快速切换/录音状态验收。
