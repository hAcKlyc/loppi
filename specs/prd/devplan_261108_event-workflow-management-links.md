# 事件详情的管理入口

「执行策略」和「编辑事件标签」弹窗右上角提供「管理」，分别进入智能分析的「流程与策略」与「事件分析·场景标签」。

## 执行台账

- 契约。复用 Modal 标题区与事件详情现有的智能分析导航，目标仅作为本次打开页签。管理入口关闭当前详情并切换页面，忙碌时跟随弹窗禁用。入口在策略列表为空时也可用。侧栏普通进入仍默认处理队列。
- 验收。用合成事件点击两个管理入口，验证目的页、焦点与弹窗退出。验证无配置写入及普通入口默认处理队列。
- 基线。 `3e578b369ead7ccbe3bca5c299b17f48230f163d`。已有录制权限按钮工作区改动不在本批范围。
- 验证。需求、故障路径与架构复核通过。前端构建、lint、138 项 Node 回归通过。Chromium 在 1440 和 760 像素窗口实际点击了两个入口，验证管理键位于标题和关闭键之间、空策略可用、焦点直达且无写入。
