# 事件级精转：已确认的设计决策

2026-10-18。本文保留本次讨论的结论与调查依据。用户已授权“确认需求，核实技术细节，然后开发测试直到完成”；具体执行契约、验证和交付状态统一见 [开发台账](../devplan_261018_event-asr.md)，实现机制见 [算法文档](../../tech_docs/algorithms.md)。旧讨论中的待决项已收敛，不再保留互相冲突的候选方案。

## 已确认的产品行为

| 决策 | 最终规则 | 用户依据 |
| --- | --- | --- |
| 精转围绕事件组织 | 粗转持续分段产出；云精转按事件内待处理音频尽量整体提交，再从返回中提取句段。 | “A->B 时间段作为一个事件……整体去做一次请求” |
| 事件稳定后自动精转 | 会议进行中持续显示粗转，减少自然延长导致的重复提交。 | “事件稳定后整场精转（推荐）” |
| 上传副本缩短长空档 | 仅缩短已确认无语音的长空档，返回结果映射到原始时间；原声和回放不变。 | “缩短上传音频的长空档（推荐）” |
| 已完成部分复用 | 自然续接只补新增，不为上下文或跨请求 speaker 编号变化重传旧音频。 | “已经精转完成的不重复识别” |

“整场”不承诺一个事件永远只有一次请求。麦克风和系统声独立处理；超出单次限制或遇到不能安全连接的真实缺口才拆分。查询同一远端任务不算新的识别提交。

## 收敛后的细节

- 自动稳定以事件末尾之后 15 分钟观察范围为默认；后续独立事件可提前收口。相关本地分析、粗转和事件拟合未完成时等待，失败显示异常；手动精转可立即规划。
- 超过 3 秒、完全有数字静音或无语音保留决策证据的空档，在上传副本缩至 1 秒。没有文件、没有粗转文字、设备断流、主动清理和未知缺音，都不能当作静音证据。
- 保留现有直传路径，单请求按压缩后最多 20 分钟规划并检查编码文件不超过 10MB。官方当前任务提交文档列出 512MB / 5h，未列单独 Base64 上限；本地限制不冒充供应商最大能力，不新增对象存储。
- Core 保存不可变输入和时间映射，并单独记录当前事件对物理识别请求的引用。媒体文件因其他区间清理而被重写时，通过现有音频清单寻找相同原始范围，不能修改已固定的上传时间轴。
- 映射接缝处只使用完整可对齐的词级证据拆句，保留文字和标点；无法可靠定位则整请求失败，无部分发布、无自动付费重转。其他已完成结果继续可用。
- 延长、裁剪、拆分、合并复用已识别覆盖、完整句段 ID、人工修订与声纹。拆分继承完整识别历史，显示时才裁剪到当前事件；删除兄弟后再延长也能复用。跨人工裁剪边界的整句暂不显示，标记部分精转，不猜字时间或自动补转。
- 已完成但无文字、有效失败、排队及在途输入都参与去重；错误不能变成自动反复付费。主动“重新精转”才建立新轮次，并沿用人工修改的可验证恢复/待核对语义。
- 旧任务没有新映射时仍以旧线性方式完成原请求查询；历史已完成任务不批量重送。只清原声保留已完成文字和已有特征，全部清理遵守墓碑，不允许迟到结果复活内容。
- 统计沿用现有页面：次数按独立受理请求，费用按实际上传音频时长，优先供应商返回计量。不新增统计指标或图表。

## 说话人为何可以跨请求匹配

API 返回文字、时间和请求内临时 speaker 标签。本机根据映射后的原声音频提取 CampPlus 特征，与同一个人物声纹库比对。因此两组云转录无需共享编号，也不需要为统一编号再识别整场。

已有合格向量可以复用，新增句段独立提取和匹配；同场匿名分组也依声音证据，而不是跨请求比较云编号。短句、噪声、重叠发言或证据不足仍可保持未确定。这个设计不承诺每句都识别人名，也不改变本次范围之外的模型和阈值。

## 调查与验证依据

重设计前的 10/18 快照：238 次受理、32 个事件、约 3.157 小时音频、估算 ¥2.52579；103 个请求不足 10 秒，同源重复覆盖约 26 分 12 秒。旧策略遇到 >3 秒空档即拆请求，事件延长又按新版本安排整段，导致请求碎和重复覆盖。这不是精转返回逐句结构所必需的。

当前计费口径与价格来源见 [云用量文档](../../tech_docs/cloud_usage.md)。供应商协议见 [任务提交](https://docs.volcengine.com/docs/DoubaoVoice/task-submission-http-1?lang=zh)与[结果查询](https://docs.volcengine.com/docs/DoubaoVoice/result-query-http-1?lang=zh)。历史长静音时间戳故障是缩短上传空档的动机，不能凭减少请求数代替时间与文字验证。

验证采用确定性回归、隔离运行和受控真实供应商对照。合成非私人双句音频由 41.553 秒缩至 12.553 秒，真实接口两句还原时间完全一致；独立声学边界最大偏差 177ms。此结果只证明该固定样本与处理路径，不代表通用 ASR 或声纹准确率。全部验收与独立审查结果以开发台账为准。
