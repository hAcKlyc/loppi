# 智能分析总览与模块页签

页面改名为「智能分析」，主标题左对齐，右侧以 HTML 展示粗转录、事件分析和事件确定后的两条支路。流程和四个模块页签复用各自的名称和图标。粗转与精转共用一枚独立素材，事件分析和策略分别使用模型与模型调节图标。

## 执行台账

- 契约。沿用 `QueueView`、`Tabs`、`TabPanel`、`ModelPreparation`、`UsageStatisticsView` 和 `WorkflowSettings`。默认进入事件分析，展示云端事件队列和标签配置。粗转录显示本地模型。精转录显示云端语音队列、待核对入口与精转规则。策略页保留自动精转首行和自定义流程统一列表。设置仍经同一份配置草稿保存，后台行为与协议延续原契约。
- 验收。用合成数据核对标题、流程、四个页签与图标，窄窗可读且无横向溢出，键盘切页有效。验证模型状态、两类云队列、设置跳转、精转编辑、标签及策略草稿和依赖确认。
- 基线。 `64ae51dbddd485de53eb780e13c4729569c347ba`。已有录音权限按钮与其测试改动不属于本批次。范围为桌面 UI、图标、直接受影响的验证和使用说明。
- 实现。流程图在正常窗口与标题并排，窄窗放到标题下方。三个独立透明图标来自生成素材，声波在粗转与精转复用。事件详情按精转或重新整理状态直接进入对应模块，正常从侧栏进入默认展示事件分析。
- 审查。需求与架构通过。故障路径审查发现精转进度入口落在默认页，已改为对应模块并通过定向复验。配置、队列、统计继续使用既有入口。
- 验证。前端构建、静态检查和 138 项 Node 回归通过。Chromium 合成资料以 1440 和 760 像素窗口各通过 39 项布局及任务交互检查，设置直达 23 项和页面加载回归通过。
