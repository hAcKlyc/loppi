# 首页之外的设计系统复核

用户要求基于新版设计系统重新审阅首页之外的界面，确认是否全部改造完成。逐页检查事件详情、队列/统计、人物列表/详情、Agent 接入、设置、首次准备、常驻入口，并修正已确认的设计与交互一致性缺陷。

## 开发契约

- 以 `specs/DESIGN.md`、`src/tokens.css` 和既有 Controls/页面/入口为来源；保持首页已确认方案、品牌母版、产品 ICON 与兔子原字节。
- 修正公共页面边距与标题、失效悬停、队列控件及状态表达等已证实遗漏；不更改信息架构、业务状态、数据与云端动作。
- 验证常规1120×760、最小760×540及大窗；长内容、空/加载/失败、选中/焦点/禁用与关键弹窗。平台样板只证明呈现，不能冒充 Windows 原生验收。
- 全部浏览器写入限隔离模拟数据，真实录音/密钥/配置不作测试对象。
- 无新增 owner、持久状态、协议、依赖或运行时恢复机制；不打包、安装或发布。
- 本轮基线为 `/tmp/loppi-secondary-design-before/` 的工作树快照；此前首页、Token、Core/Windows 与文档改动不计入本轮 delta。

### 初步发现

Agent 页另配页边距/标题样式；队列使用私有开关而非公共 Switch；设置页覆写按钮底色，使公共 hover 被覆盖；统计图例底色与 hover 在合并 Token 后相同。补充真实任务/注意/失败样例后核对队列反馈颜色。其余页面继续按实际结果判断，不机械重做已符合规范的模块。

### 用户追加：开关状态必须清楚

用户明确指出炭黑开启与深灰关闭过于接近，要求开启使用主题红。此前规范中的“开关中性选中”按此最新要求替换：`color-switch-on` 复用主题深暖红基础色、`color-switch-off` 保留中性灰，白色圆钮左右位置与已确认的布尔值一致；设置、队列共用同一组件与 Token。启用不冒充实际采集，导航/分段选择仍中性。检查两类轨道对白色圆钮/页面的必要图形对比度、禁用与确认失败语义。

### 独立审查修正

需求审查发现统计图固定900×252 viewBox把窄窗刻度缩到约7.6px，违反既有元信息字号规范，判为本次审阅明确负责的问题。在现有 UsageChart 内测量实际SVG宽度，viewBox/横向数据/指针/键盘范围共用该宽度，保持12px刻度与原252高坐标；组件本地ResizeObserver在卸载时断开，不引入业务状态、请求或新owner。64组场景补入实际SVG屏幕字号与裁切检查并通过；真实同一挂载790→582宽度，12px字体与14px字框保持，鼠标/键盘定位正确。需求与故障定向复核均PASS，最终全新架构复核PASS，无剩余阻塞或必需证据缺口。
