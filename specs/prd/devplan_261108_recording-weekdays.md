# 定时录制按星期重复

在录制计划弹窗中以一行七天选择重复日，共用一组开始和停止时间。默认全选，取消全部时不可保存。跨午夜归属于开始日，并在界面显示次日停止。设置显示已保存的日期、时间和下一次动作。

## 执行台账

- 契约。Core 同一写事务保存星期、时间、启用状态和游标。旧计划默认全选，旧格式写入省略星期时保留当前选择。复用现有本地日历、启停动作、保存修订和睡眠恢复，不新增计时器。GUI 与 CLI 读写同一计划。
- 兼容。保留既有录制计划表的列布局，星期字段与其一一对应。业务协议随配套组件推进，防止新客户端向旧 Core 提交后静默丢失星期选择。
- 验收。验证旧计划升级保留开关和游标，周五跨周六停止，未选日期、回拨、夏令时、最近遗漏动作、保存取消及空选择。用隔离数据测试实际 CLI，在本机原生开发包打开安装版数据，仅查看界面。
- 基线。 `242e3e9`。另有待授权按钮的未提交改动，保留其所有权。范围为录制计划 GUI、Core、协议、CLI、回归与对应文档。
- 验收。实现 `8ec79b1`。Mac 完整验证 22 项通过，夏令时修复后定向 Core 测试 11 项通过，含 Lord Howe 缺失时刻与 Nuuk 跨日冲突。真实隔离 IPC 验证未来定时执行、恢复与回执，CLI 验证选星期、省略保持和空选拒绝。760×600 浏览器验证 28 项交互。Windows 日历代码在 Mac 运行 4 项共用用例通过，完整 Windows 交叉构建缺少 MinGW。独立审查通过。
- 实机。Apple Silicon 开发包构建通过，四组件为同一源码和协议 28。打开安装版数据时保留既有启用状态和 08:00–23:00，迁移后七天全选。原生界面停留在编辑录制计划弹窗。
