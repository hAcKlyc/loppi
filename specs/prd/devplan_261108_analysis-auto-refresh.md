# 智能分析自动更新和命名

移除页头刷新按钮。打开智能分析或切回处理队列时更新当前数据，打开任务明细时更新任务与核对项。保留原有轮询、失败重试及配置草稿。队列卡片使用「语音识别·精转录」，两个配置页签使用「事件分析·场景标签」和「流程与策略」。

场景标签页在单选／多选前显示「每个事件支持智能打标签模式」，标签列表以「场景标签管理」为标题。
