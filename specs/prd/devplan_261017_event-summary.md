# 事件内容摘要

目标：自动事件整理一次返回时间范围、标题和可读摘要，列表展示摘要而非错乱转录摘句。无法概括时留空；实时记录/未整理素材仍展示真实素材。历史无摘要事件显示诚实占位，不自动付费回填。

## 执行台账
### 开发约定
- Core 的 named_events 持久化可空摘要，沿现有 LLM 输入、publish_fit 事务、TimelineItem 到 UI；无新队列、无独立云调用。
- 摘要来自粗转，不能保证识别内容正确；提示词要求仅概括可确认内容，不补造人物、决定、数字。
- 延续事件使用前文摘要生成整体摘要；重跑同一候选提供关联事件上下文。摘要上下文变化、手工改范围/来源、清除内容、人工纠错时不得保留失效摘要。
- 老数据库迁移为 NULL，旧格式返回允许无摘要；不变更历史候选策略哈希，避免付费批量重跑。新增 IPC 可选字段维持版本 16。
- 列表命名事件优先摘要，无摘要显示占位；未整理/实时素材原有摘录与交互保留。
- 不做精转后自动再次摘要、摘要编辑、历史批量重算、ASR识别质量修复。
### 验收与结束条件
- 内存数据库测试：迁移、保存/读取、同范围摘要更新、跨窗合并、迟到上下文、边界编辑与清理失效、空/超长摘要。
- UI测试：摘要优先、非精转标签、无摘要占位、实时摘录不变。
- typecheck/lint/build/Rust tests/clippy，需求+对抗审查后最终架构审查，签名本机构建与 UI/记录状态检查。
