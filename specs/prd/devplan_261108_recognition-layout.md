# 智能识别配置页视觉重排

智能标签和自动流程的首屏直接呈现规则、数据与操作。标签与判断标准横向对齐，策略按名称、输入、触发条件排列。精转条件与命中标签在同一组控件内。解释只在相关控件或需要反馈的状态中出现。

## 执行台账

- 开发契约。保留单选与多选、标签编辑、精转筛选、策略编辑、共享草稿及 Core 依赖确认。沿用 `WorkflowSettings`、`SegmentedOptions`、`Button`、`IconButton` 和 `Modal`。此次变更限桌面表现层，无新增配置机制或协议。
- 验收。核对默认和含样例配置、760 像素宽度、键盘、长名称和触发标签换行。重跑识别导航与事件详情回归，验证保存后仍读回同一配置。
