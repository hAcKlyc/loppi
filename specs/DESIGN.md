# loppi 设计系统

更新：2026-11-01。适用：macOS 与 Windows 应用、常驻入口、品牌资源及项目发布物料。

首页以日概览、时间栏与中性记录卡片组织内容；进行中状态集中在标签与时间轴。全部前端通过同一套分层 token 实现。原产品 ICON 与状态兔子保持独立。

事件详情在顶部时间、标题下显示真实处理状态；「等待事件稳定」可点击确认结束，弹窗预填当前起止日期时间并允许修改。事件已确认结束与精转进度并列，不把排队/处理中显示成精转完成。顶部只保留更多与关闭，编辑、导出、清理、拆分、合并、取消标注、重新精转及查看识别队列收进更多菜单；播放、正文切换与现场记录仍可直接操作。菜单支持键盘、Escape及点击外部关闭，关闭确认弹窗后回到触发入口。

本文是项目统一的视觉与交互规范，定义应遵守的规则。实现进度、检查与构建证据见[设计交付台账](prd/devplan_261031_design-system-renewal.md)与[Windows 交付台账](prd/devplan_261101_windows-release.md)。概念图表达方向，不作为精确尺寸、业务事实或字体来源。产品行为以相关 PRD 与[架构](ARCHITECTURE.md)为准。

Windows 主窗口保留原生标题栏与窗口操作，标题栏使用 `color-canvas` / `color-text`，去除突兀的外沿色。原生颜色在构建时从同一 token 源解析；高对比度启动时保留系统样式。关闭窗口沿用后台记录行为，不等同于退出。macOS 保留原生交通灯。

## 1. 品牌与设计判断

**loppi 是安静的桌边伙伴。** 它在用户启用、电脑可用时留下声音，在需要时帮助用户回到一段经历。温度来自兔子的回应、清楚的内容和体贴的操作。用户无需照顾角色或管理录音仪表盘。

- 产品名称统一小写 `loppi`；不另造中文名。
- 视觉基调：偏暖中性白、炭黑、柔和绿与陶红；现代无衬线文字，稳定时间刻度，清楚的阅读层级。
- 主角是用户的经历；兔子承担生命感与录音状态，字标承担品牌识别。
- 用对齐、留白、层级和少量细线建立秩序。避免层层卡片、装饰波形、持续扫光、闪烁录制灯和大面积状态色。
- 简洁不隐藏事实：中断、尚未处理、空结果和读取失败分别说明，并提供对应操作。

## 3. 色彩系统

### 基础色

| 基础色 | 色值 | 用途 |
| --- | --- | --- |
| 炭黑 | `#292C28` | 主文字、主要操作、字标主体 |
| 纸白 | `#F6F5F1` | 页面与阅读背景 |
| 暖石色 | `#ECEBE5` | 次级表面与控件分组 |
| 柔和绿 | `#93B29C` | 已留存、已完成的记录标记 |
| 柔和暖红 | `#D6A08A` | 活跃录制区间与播放位置图形；状态文字与当前指针使用深色派生色 |
| 深暖红 | `#B65B42` | 字标 i 方点、品牌细节与已启用的布尔开关 |

这六色是品牌主色组，不是全部 UI 颜色。中性色、状态色组、悬停、焦点、图表与深色入口的完整色组见 tokens。浅绿和浅暖红用于图形/表面，不直接作为小号正文色。

### Token 契约

`src/tokens.css` 是数值唯一来源，依次组织基础值、语义角色、共享组件/布局。CSS 和 JSON 导出由脚本生成，禁止手工维护副本。

| 类别 | 规则 |
| --- | --- |
| 色彩 | 基础值只定义在 `palette-*`；组件使用 `color-*` 或 `entry-*`，不直接挑基础色。正式素材生成器也从同一源解析颜色 |
| 中性色 | 纸白页面、暖白卡片、暖石分组/选择；卡片与控件分别使用对应悬停色，共用次级文字灰、装饰线与交互边界；不为每页另配灰阶 |
| 字体与尺度 | `font/type/weight/tracking/leading`；文字与数值分别使用系统无衬线和等宽数字 |
| 间距、形状与描边 | `space/radius/stroke`；小幅光学校准可用现有 token 计算，不再增加近似常数 |
| 层级与反馈 | `shadow/ring/motion/ease/opacity/layer`；减少动态分支关闭过渡与装饰动画 |
| 组件与布局 | 控件高度、图标、字标、侧栏、时间轨道、表单/抽屉/弹层宽度及组件边界；普通样式通过变量消费 |
| 例外 | 媒体查询保留 1100/1000/850/760px 字面阈值（CSS变量不能直接驱动媒体查询）；SVG路径、像素图、数据坐标、原生宿主实时几何保留原所属来源 |

中性色不同职责可以指向同一个基础值。`muted/faint/secondary` 当前共用 `#62655F`，通过字号、位置和字重分层。普通首页不应展示整套功能色；警告、失败、图表与深色入口只在对应事实出现时使用。产品 ICON/兔子的图像像素不计入 UI 色板，不能为缩减颜色数量重绘它们。

### 关键颜色角色

| 使用位置 | 语义 token | 约束 |
| --- | --- | --- |
| 页面 / 阅读卡片 / 辅助分组 | `color-canvas` / `color-surface` / `color-surface-subtle` | 三层表面保持可辨，侧栏用 `color-sidebar` |
| 卡片 / 控件悬停 | `color-surface-card-hover` / `color-control-hover` | 同类组件共用，不因录制状态改变整卡颜色 |
| 开关开启 / 关闭 | `color-switch-on` / `color-switch-off` | 主题暖红 / 浅灰；关闭轨道与白色圆钮用 `color-switch-off-border` 细描边保留辨识度，圆钮位置同时表达状态 |
| 正文 / 次级文字 | `color-text` / `color-text-secondary` | 按真实背景校验对比度 |
| 已整理 / 未整理留存 | `color-complete` / `color-unorganized` | 平涂深浅绿，不加线框 |
| 正在记录标签 | `color-live-soft` 背景 + `color-live-text` 文字与点 | 卡片保持 `color-surface` |
| 活跃录制轴段 | `color-recording-surface` / `color-recording-surface-hover` | 与标签同暖红色系；这两个 token 用于轴段，不用于整卡 |
| 右上录制状态 / 当前时刻线与时间 | `color-live-text` | 深暖红；位置线不证明录音已启用 |
| 字标 i 方点 | `color-logo-dot` | 批准母版的品牌深暖红，与状态文字角色独立 |
| 注意 / 失败 | `color-warning-*` / `color-danger*` | 琥珀 / 深莓红，与普通录制区分 |
| 深色入口 | `entry-*` | 独立表面与可读文字配对，不作为主窗口主题 |

运行 `npm run design:build` 重建 CSS/JSON、使用样张、品牌导出、发布封面、真实组件预览与资源清单；不会重新拍摄截图。`scripts/test_design_assets.mjs` 检查引用完整性、实际颜色对比、禁用私配色和资产一致性，`scripts/test_entry.mjs` 检查入口 token 与原生命中轮廓一致。

### 状态语义

| 事实 | 表达 |
| --- | --- |
| 记录已结束/素材已留存、笔记已保存 | 绿色小标记，正文保持炭黑 |
| 正在记录、当前播放/定位、当前时间 | 暖红标记、细线或浅底，配实际状态文字 |
| 主动暂停/尚未启用 | 中性文字与睡眠兔子，保留开始/继续操作 |
| 启停在途、连接或结果未知 | 中性等待；不提前显示成功，不无限沿用旧健康状态 |
| 阻断/来源缺失 | 琥珀提示、原因与恢复入口；角色保持清醒 |
| 失败、破坏性动作 | 深莓红与明确动作/原因；文字和图形区分普通暖红进行中 |
| 开关已启用 | 主题暖红轨道、圆钮在右；关闭用浅灰轨道和细描边、圆钮在左。表示该项已启用，不独立证明正在采集 |
| 导航、分段选择、输入焦点 | 中性操作色；选中不等于已完成，不普遍涂绿 |

录音事实、识别/整理进度与保存结果分别表达。绿色录音区间不表示精转或所有云任务已完成；进行中暖红不表示故障。颜色同时有文字、位置或形状支持。

常驻入口使用不透明暖黑表面、奶白/浅灰文字与图标，不引申为主窗口深色主题。深色入口的强调文字使用同陶红色系较亮派生色，单独经基础/操作/悬停三个真实背景验证4.5:1，不直接照搬白色界面的轴段色。图表多序列颜色只区分数据，并与图例一致。

## 4. 字标、兔子与图标

### 字标

- 使用 SVG 轮廓母版，禁止依赖电脑字体重排；提供彩色、单色、反白与透明 PNG。
- 保持完整连续的小写字形；i 点为深暖红简单方点。禁止阶梯、耳朵、渐变或额外图形替代方点。
- 四周至少保留一个 i 点边长的净空；保持母版比例，不拉伸、重排字距或叠加阴影。
- 普通文字中的 `loppi` 使用界面字体，不为每次产品名出现嵌入标志。

### 角色

- 使用现有薄荷像素兔：清醒双竖耳、奶油口鼻/胸腹、桃色耳内；暂停趴睡。保持像素边缘、透明背景与稳定基线。
- 主窗、顶部、悬浮入口复用 `Rabbit` 与同一动画清单；等待、部分异常和中断与主动睡眠区分。
- 常驻轻微呼吸与偶尔眨眼；靠近回应、保存确认、暂停/恢复过渡播放一次。只在确认实际结果后改变姿态。
- 悬停、音量、彩蛋或刷新不改变录音事实。减少动态、不可见或资源失败时保留正确静态姿态。
- 产品 ICON 固定保留现有“一耳折、一耳直、歪头”的近景形象；它与双竖耳倾听状态动画独立，不互相替换。现有图标源图、各尺寸 PNG 与 ICNS 保持不变；Windows ICO 只能由同一方形母版派生。
- 图标导出复用现有方形母版与平台蒙版；小尺寸检查耳形、脸部和轮廓，不因动画造型不同重绘 ICON。

### 功能图标

使用同一线性语言，默认 18px、约 1.6px 圆端笔画。纯图标按钮有可访问名称与悬停/聚焦提示。品牌像素不扩展为整套像素字体或难辨控件。

## 5. 文字、空间与表面

- 使用系统无衬线及系统中文回退：macOS 优先 SF/PingFang，Windows 使用 Segoe UI/Microsoft YaHei UI；不依赖在线字体。时间、用量、时长用等宽数字，正文保持自然字距。
- 基本层级：正文/控件 14px，长转录 15px，条目标题 16px，页面标题 26px，日期 32px；元信息 12–13px。重要内容不靠缩小文字塞入窗口。
- 正文行高约 1.6，长阅读约 1.75；400/500/600 字重为主。标题、正文、元信息形成层级，避免全部加粗。
- 4px 主节奏，2px 光学校准。小标记 4px、轻控件 8px、常规控件 10px、记录卡 12px、概览/面板 16px、较大容器 20px；胶囊限于开关/头像等合适用途。
- 纸白页面、暖石辅助分组、白色阅读表面；列表通过对齐、分组和留白建立秩序；细线或卡片按页面审阅结果确定，字段范围可辨。
- 阴影只表达菜单、抽屉和弹窗深度；常规条目不悬浮，不因悬停移动。
- 必要文字在实际背景至少 4.5:1，大字和必要图形至少 3:1。低对比仅用于辅助表面、装饰线或有等价文字/形状的色点。

## 6. 窗口、导航与滚动

主窗口内容区初始 1120×760、最小 760×540，均为逻辑像素。保留时间线、处理队列、人物库、Agent 接入、设置五页。主窗口浅色；本轮不增加搜索页、顶部导航或新信息架构。

- 常规侧栏左上角使用圆润矢量字标与深暖红 i 方点；紧凑侧栏使用原产品 ICON。字标不以普通文本替代。
- 保留侧栏、日期导航与右上录音控件的职责关系。常规/紧凑宽度、内容上限、时间栏、抽屉宽度从布局 token 读取。
- 1100px 及以下收紧留白；850px 及以下采用紧凑图标导航，保留名称、焦点和点击区域；日期与录音操作不挤出窗口。
- 大窗口增加外围留白，正文/表单不无限拉宽；长标题、姓名、状态和说明允许换行。
- 独立页面复用 `page-container` / `page-heading` 的页边距和标题层级；局部表单、代码或阅读内容按组件限宽，不另配整页边距。控件悬停沿用公共角色，局部样式不得覆盖掉反馈。
- 页面、转录、现场记录在所属区域滚动。弹窗限于可用高度，关闭/提交可达；不提高根最小高度掩盖溢出。
- macOS 原生红绿灯有专属净空，Overlay 标题栏不另画横贯标题行。Windows 使用系统标题栏，Web 内容不再为红绿灯额外留位。保留空白拖动区，交互、选择文字和透明入口命中不受影响；任务明细的标题拖动区域从标题本身开始，不向上覆盖独立返回按钮。

## 7. 公共交互

复用 [Controls.tsx](../src/Controls.tsx)，不另造同义按钮、表单或弹窗机制。

| 元素 | 规则 |
| --- | --- |
| 主操作 | 炭黑实底、纸白文字；每个任务区域一个主要提交动作 |
| 次操作/轻操作 | 中性填充或文字，稳定尺寸；悬停只改变表面/颜色 |
| 危险操作 | 明确对象、范围与后果，危险色与既有确认流程 |
| Field/输入 | 可见标签与关联描述/错误；失败保留草稿，敏感值不普通回显 |
| Switch | 开启暖红、关闭中性灰，圆钮保持清晰对比；语义与圆钮位置跟随已确认状态，应用中阻止重复提交 |
| 分段选择 | 中性选中、键盘可用；保持互斥语义与可见焦点 |
| Tabs | 与内容同区域，文字/下划线支持选中，布局稳定 |
| Modal/Drawer/Popover | 沿用焦点、Esc、关闭与返回契约；关闭不伪装保存，长内容可滚动 |
| 加载/空白/失败 | 首次加载、空结果和失败分开；刷新保留已有内容与位置；失败提供重试 |
| 在途/未知 | 沿用请求确认；回执不等于业务生效，不重复创建付费任务 |
| 反馈 | 成功短暂原位或轻提示；失败说明恢复动作；不弹主窗庆祝或强抢焦点 |

所有交互有可见键盘焦点。必要提示不只依赖鼠标悬停；禁用/处理中可感知，布局稳定。

## 8. 场景规范

### 时间线

- 一次一个自然日，按倒序浏览：左箭头跳到下一个有记录的日期（更新），右箭头跳到上一个有记录的日期（更早），跨月/跨年跳过空日；不存在对应记录或尚未读到可用性时禁用该箭头。日历与“回到今天”保留直接选择；历史显示回到今天，跨年补充年份。日期是唯一月历入口，关闭返回该按钮；日期列按最长日期和跨年说明预留固定宽度，数字等宽；两箭头靠近日期并与日期/星期组合垂直居中，切换时坐标不跳动。日期及页面标题属于不可选文字的界面区域，保留点击和原生窗口操作；正文、转录及表单保持可选择/编辑。列表最新在上，跨日事件保留真实身份。
- 日概览置于白色圆角卡片；两声源共享真实时间，24px轨道与记录段同高，红/绿区间完整填充轨道的上下边界，不保留无含义的全宽灰色底带。记录段高度引用轨道token；真实缺口仍按已有时段局部叠加纹理，缺口与未整理可辨，未来不生成内容。
- 已留存区间为绿；真实活跃区间为柔和陶红，与对应卡片的「正在记录」标签共用暖红色系。卡片整体保持中性，不用整卡红底或左侧装饰色线。深暖红用于标签文字/点、右上录制状态及当前时刻指针；正在记录条目的其余元信息与时间节点使用中性色，已留存条目的节点使用绿。当前时刻线仅作定位，不独立证明录音；当天在红线正上方显示纯HH:MM，图例不重复显示“现在”。标签使用独立通道，文字在两端内收、线仍精确定位；历史不显示当前时刻。悬停定位标签优先，离开恢复当前标签。
- 未整理留存使用平涂浅薄荷绿，已整理使用薄荷绿；不加常驻描边或内阴影。轨道、红绿区间和图例统一2px小圆角，短录制段沿用同一规则，不做胶囊。正常列表为空显示“暂无有效事件”；加载和失败不显示空态。
- 进行中和已完成卡片共用暖白底与中性悬停，仅进行中的「正在记录」标签使用浅暖红底、深暖红文字/点，沿用4px小圆角。颜色角色按上表读取，不为整卡增加色线、色环或阴影。卡片文字在真实表面保持对比度；空/加载/失败/暂停不伪装成录制。
- 左栏显示开始时间，卡片内显示完整区间及真实声音来源；不重复显示“粗转/精转/内容摘要”类型标签，处理与录音状态保留在右侧。两处时间共用12px等宽字与首行基准；节点为6px纯色点，不加外圈/描边/阴影，已留存用绿、进行中用中性灰。细线使用装饰边界色，按节点中轴连接真实相邻记录。单条、末条和空列表不画尾线。条目通过时间、标题、真实摘要/摘录与必要元信息建立层级，新建事件为次操作。
- 已保存重点、笔记、截图在原两条声源轨道上叠加细竖线与顶部小旗，精确对应真实时刻，不新增“现场记录”一行，不改变音频色块或范围。使用既有绿色语义表示已保存；悬停及无障碍名称说明类型与时间，键盘可定位并打开原详情。当前时间仍为红线，与保存标记独立。
- 录制显示依据 `liveCard` 与宿主快照；暂停/历史/未知不显示正在记录，处理失败单独保留。
- 普通未整理历史显隐沿用现有投影；命名事件、主动记录、异常和当前记录保持可见。视觉不改变素材或筛选语义。
- 新建表单提交一次性整理指示，完成前原内容可用；摘要缺失诚实说明，不把摘句冒充摘要。

### 详情与现场记录

- 双栏：左侧播放器、工具和转录，右侧现场记录与底部笔记输入；支持窗口内两栏可读、可滚动。
- 播放器紧凑清楚，暖红进度与浅底高亮，时间/来源/正文对齐，不展示伪波形。
- 句段按真实时间/来源定位；回放、文字、声纹可用性分别判断。分页/刷新保留位置，主动定位才滚动到目标。
- 人物、来源、人工修正标注真实；操作贴近内容，沿用人物选择浮层和作用范围。
- 笔记/重点/截图按发生时刻排列；已保存标记为绿，类型有名称/图标。原图与识别文字独立，空结果/失败不影响原图。
- 使用“保存笔记”，保留原时间锚点和失败草稿。输入为完整可聚焦表面，避免聊天气泡与发送语义。

### 常驻入口

- 收起只有兔子，不持续显示计时、波形或闪烁灯；展开为统一暖黑表面。
- 入口外轮廓遵循原生命中几何：macOS 顶部下角 26px，Windows 托盘展开面板四角 26px，悬浮菜单四角 20px。Windows 没有刘海占位；同一 `top` 持久模式显示为“系统托盘”。CSS 与宿主区域在实际 DPI 下保持一致，避免可见边角穿透到下层窗口。
- 顶部入口在状态栏高度内使用缩小的既有反白 loppi 字标，与下方兔子共用垂直中线，陶红方点保持不变；下方兔子与右侧两行整体等高居中；右侧第一行截图/重点，第二行单行评论框。原生展开完成并确认取得键盘后自动聚焦，回车保存；中文输入法确认不提交，Esc/外部点击收起并保留草稿。兔子保留暂停/继续；悬浮入口保留单击重点、拖动吸附和原菜单。
- 实际结果驱动反馈；透明区域穿透。草稿、屏幕边缘、全屏和键盘行为沿用[入口契约](prd/prd_0.1_quiet-rabbit-entry.md)。

### 队列、人物与 Agent 接入

- “智能识别”使用“事件分析”“语音识别”两张卡片，标题/说明与设置页一致；常态开关表达开启/暂停，不再重复显示“运行中/已暂停”。开关左侧设置按钮直达并聚焦对应配置行，不自动打开密钥对话框。未配置、受阻等必要提示保留。卡片下方直接展示统计图与范围选择，不设置队列/统计数据页签。
- 卡片计数右侧提供“任务明细”，二级视图仅展示对应服务任务；左上角返回智能识别，保留统计范围与指标选择。重试操作及语音识别的待核对工作流保持可达。页面滚动位置按页面生命周期隔离；主页面与二级视图切换回到顶部并给出合理键盘焦点。
- 队列区分本地录音与两类云任务；类型、范围、进度、失败/重试清楚。统计图例稳定，缺失用量不当零，费用标为估算。
- 人物列表/详情简明，姓名、声纹、来源明确；样例播放互斥、离开停止，删除沿用确认。
- Agent 接入保留 CLI/MCP 选择、真实配置与复制反馈；代码可换行、可复制，装饰不遮蔽内容。

### 设置与首次准备

- 设置沿用通用、录制、识别整理、存储数据分组；标题/短状态同一行，说明在下、动作右侧，窄窗换行。
- 授权、选中来源与实际采集分别表达；定时、容量、凭据、导出、清理沿用各自保存/确认契约。
- 首次准备集中呈现本地组件检查、声音授权和云配置。组件随应用提供，不能写成运行时需要下载；保留外发与按量付费信息。
- 完成准备进入时间线，不自动开始首次记录；之后重新打开应用，由 Core 按已保存的启用/暂停意图、声源和定时策略恢复记录。界面就绪不等于采集已开始；稍后设置、升级和授权恢复沿用既有行为。

## 9. 动效与文案

- 反馈约 120ms、常规约 180ms、布局约 300ms，具体读取 token。角色采用帧时长，不为装饰增加持续 60fps 循环。
- 动效解释状态/位置，连续操作从当前画面继续；减少动态直接到终态且保留信息。
- 短而具体的中文，先说事实/结果，再给必要动作。产品名小写；避免拟人自责、索取陪伴、夸张庆祝与内部实现术语。
- 对外如实说明“电脑可用且用户启用时持续记录”、本地保存与已配置的云处理；不暗示无条件 24 小时或全部离线。

## 10. 变更与验收

新增设计先查已有 token、组件和角色资源。规范、母版、实际界面同步更新；导出由源文件重建，不在多个尺寸中分别修改。

交付至少检查：

1. 资产：透明边缘、像素清晰、比例、小尺寸/深浅背景、正式源文件与清单。
2. 组件：鼠标/键盘焦点、禁用/在途/错误、弹层关闭/返回与长文字。
3. 场景：主窗、详情、辅助页面和入口；空/密集/跨日/长转录、录制/暂停/等待/异常。
4. 尺度：1120×760、760×540 和大窗口，文字/控制不重叠、不可达或被裁切。
5. 一致性：色彩角色稳定，状态有文字/形状支持；无未定义变量或旧风格覆盖。
6. 实机：浏览器证明 Web 布局/交互，签名安装版证明原生窗口、入口命中和重启，证据分别记录。

结果保存在交付台账与证据目录，实际通过才标记完成。本文不承载历史日志或未执行的验收声明。

## 11. 平台呈现

- 保持同一品牌、颜色角色、共享组件和业务状态。平台判断只决定文案与窗口净空，录音/权限/模型准备始终读取原生/Core事实。
- Windows 麦克风指引对应桌面应用访问权限，电脑声音对应输出设备检查；不能要求用户寻找macOS的“屏幕与系统音频录制”权限。未开始实际采集时不把设备“已准备”写成“正在记录”。
- Windows 电脑声音与桌面截图分别读取原生事实。锁屏造成截图不可用时，不能展示为电脑声音授权丢失，也不能保存黑屏冒充截图成功。
- 密钥提示使用“本机/系统安全存储”，适用于两端安全凭据后端；错误不得回显密钥。
- Windows 托盘与悬浮入口沿用同一状态兔子及动作反馈，不另造状态枚举；主图标保持折耳歪头形象。
- 浏览器mock平台只证明呈现；原生标题栏、托盘、DPI/命中、音频与安装验收必须有对应操作系统的真实证据。
