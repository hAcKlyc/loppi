# 粗转窗口发布与摘要修复：三遍对照方案

## 问题与候选

不切精转、不切模型。重复 JSON 字段在进入普通对象前拒绝；非法时间在任何事件写入前拒绝整窗，复用既有最多三次格式重试。摘要改为同次调用内的句子增量：未改句保留，新增追加，后文纠正以明确旧句下标和本窗证据替换。数据库仍存完整 summary 字符串，前端和存储不增加长度限制。

这是通用契约调整，没有针对真实样本的人名、数字、业务词或特例。句子下标从已保存摘要临时派生，没有新持久状态、总结调用或全量原文重送。模型仍可能漏提新信息、误解条件或错误替换；程序保留保证不等于语义全对。

## 冻结与可比性

- 基线：`../2026-10-24-coarse-precise-evaluation/` 的 coarse 三遍，使用已有原始结果，不重新选择最好的一遍。
- 候选：同 12 段粗转，0.52–81.26 分钟，共 206.37 分钟；相同原始字节、事件范围和 21 个窗口。
- 每例独立跑三遍，共 36 次，计划 63 个窗口调用；每次从空隔离数据库起步。
- 两组均 deepseek-flash、high、120 秒。生产 low/60 秒保持原样；本实验不证明生产时限下同样的成功率。
- 固定随机顺序、最多两并发。prompt、schema、gold、二进制均留哈希。候选 prompt 与生产源码一致。
- 只访问既有云端模型，不重做 ASR，不修改活跃库或安装包。
- 实验不自动重试：拒绝、超时、失败均保留并进入分母，不能将安全拒绝当作完整成功。生产的已有有界重试另由测试验证。

## 指标

| 指标 | 分母及含义 |
|---|---|
| 完整产出 | 36 次中全部窗口完成并有最终数据库结果；失败时的保留快照单列 |
| 严格结构通过 | 原始 JSON 唯一键、schema、时间、引用、更新合并和实际 SQL 全部一致 |
| 静默损失防护 | 对旧 126 份真实响应离线检查；6 个重复字段、1 个非法时间必须拒绝，不能覆盖/跳过后 complete |
| 关键事实覆盖 | 沿用冻结 46 项复合事实，12 例等权平均；另列总 138 个机会。缺最终结果计 0 |
| 摘要事实覆盖 | 同一事实仅从最终 summary 评分；不以其他字段补齐，不等同可读性总分 |
| 跨窗保留 | c09/c10/c11 指定早期事实在末窗前首次正确出现，最终是否仍完整正确；summary 单独计算 |
| 语义错误 | 明确改义、无依据身份、条件/状态错误；遗漏不重复计错，来源本身含糊时保守裁决 |
| 三遍稳定 | 同例三遍均结构通过且无明确语义错；这个指标允许事实遗漏，不能叫全面正确率 |
| 成本与时延 | 实际调用数、失败数、p50/p95、超过 60 秒次数、供应商 token；失败也计入 |
| 摘要体积 | 字符数中位数/最大值，防止把“保留了”误等同“足够简洁” |

## 评分与核验

完整产出逐例核查实际粗转、最终保存 JSON、逐窗快照及引用；沿用前轮 gold、source anchors 和 scoring errata。复合事实只有完整表达且无相反陈述才为 1；没有音频人工真值，评估是来源文本相对的 Agent 复核加主评审裁决。

先完成生产回归、旧响应离线检查及独立代码审查，再冻结正式候选。最终报告同时给出量化和典型失败/改善案例。任何候选迭代保留旧失败结果，禁止挑选三遍中的最好结果；最终候选仍需完整三遍。

隐私材料位于被忽略的 `private/`：输入、响应、隔离数据库、逐例评分、完整前后结果。公开提交仅保留匿名报告、契约、prompt/schema 与汇总指标。
