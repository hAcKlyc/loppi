## 阅读口径

1. **产品规则**以 [PRD](../prd/prd_0.1.md) 为准；这里解释当前代码怎样实现，以及尚未满足的规则。
2. **当前行为**以此工作树的代码为准。文中给出模块和函数入口；数值阈值属于当前策略版本，改代码时应同步更新文档。
3. [技术 RFC](../prd/tech_rfc_0.1.md) 保留调研、方案演进和实测证据；它含早期方案，不应逐段当作当前实现。[开发计划](../../plan.md)记录验收门槛与暂停前进度。
   [安静兔子入口 RFC](../prd/tech_rfc_0.1_quiet-rabbit-entry.md)是已接受的方案，关联正在实现的[功能 PRD](../prd/prd_0.1_quiet-rabbit-entry.md)；生产入口和协议已修改，原生验收状态见 PRD 执行台账。
4. “云端说话人分段”“同场匿名说话人合组”“跨事件人物身份”是三个不同输出。前两者不会自动产生真实姓名。

## 当前主要边界

- macOS GUI、CLI 和登录项共用一个本机核心；SQLite 与媒体目录由核心管理。没有 hear 自建云服务。
- LLM 只接收候选的粗文字、来源和时间；ASR 只接收待精转范围的音频。人物库与声纹特征在本机处理。
- `PROTOCOL_VERSION=15` 是当前工作树协议号，不代表 0.1 已通过发行验收。
- 说话人准确度、关屏/睡眠时的系统声、设备异常恢复、完整长时资源和公证安装仍有未关闭门槛，详见 [plan.md](../../plan.md)。
