## 阅读口径

1. **产品规则**结合原 0.1 PRD 与后续功能 PRD 阅读；原 PRD 顶部列出已被后续实现替代的规则。当前使用、隐私与分发以公开指南和对应 Release 为准。
2. **当前行为**以此工作树的代码为准。文中给出模块和函数入口；数值阈值属于当前策略版本，改代码时应同步更新文档。
3. [技术 RFC](../prd/tech_rfc_0.1.md) 保留调研、方案演进和实测证据；它含早期方案，不应逐段当作当前实现。[开发计划](../../plan.md)记录验收门槛与暂停前进度。
   [安静兔子入口 RFC](../prd/tech_rfc_0.1_quiet-rabbit-entry.md)是已接受的方案，关联正在实现的[功能 PRD](../prd/prd_0.1_quiet-rabbit-entry.md)；生产入口和协议已修改，原生验收状态见 PRD 执行台账。
4. “云端说话人分段”“同场匿名说话人合组”“跨事件人物身份”是三个不同输出。前两者不会自动产生真实姓名。

## 当前主要边界

- macOS 与 Windows 的 GUI、CLI 和系统启动入口共用本机核心；SQLite 与媒体目录由核心管理。没有 loppi 自建云服务。
- LLM 接收候选的粗文字、来源、时间及主动保存的新截图原图；ASR 接收待精转范围的音频。人物库与声纹特征在本机处理。队列、保留与删除边界见 [PRIVACY.md](../../PRIVACY.md)。
- `PROTOCOL_VERSION=26` 是当前工作树协议号，不代表 0.1 已通过发行验收。
- 精转文字依据请求时间轴和归属发布；声纹与回放独立验证真实原声。长静默、VAD 或当前媒体留存不再否定已返回文字，详见 [本次修复与验证](../research/2026-10-22-asr-publication-failures.md)。
- 平台覆盖、签名和已发行包见[版本说明](../../docs/releases.md)。历史 plan 中的待验收项不替代新版本记录，Windows 最新候选见其执行台账。

本目录不存 API Key、用户原声、私人转录、私人截图或声纹向量。界面截图使用合成或公开样本，验收摘要不附真实录音库。
