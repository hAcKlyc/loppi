# 智能识别任务明细返回按钮修复

2026-11-03，macOS ARM，in-app browser 1280×720；`scripts/test_recognition_navigation.html` 挂载真实App，使用合成队列/统计/任务和隔离IPC，不读取真实录音或调用云服务。

## 原因与修复

任务明细的返回按钮位于 `.page-heading` 之前。标题的透明 `::before` 拖动区域原本向上延伸60px，其层叠区域挡住返回按钮。修复前按钮中心命中的是 `.page-heading`，真实坐标点击后仍停在任务明细；直接调用按钮click或辅助功能动作会成功，原有程序化导航测试因此没有发现遮挡。

只在标题前有 `.recognition-back` 时，让标题拖动区域从标题自身顶部开始；不抬高按钮层级或改动导航状态。现有返回事件、聚焦和统计实例继续沿原路径执行。
