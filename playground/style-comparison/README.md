# hear 设计语言对比

交付文件：`../hear-style-comparison.html`。这是包含脚本、样式与兔子资源的单文件 HTML，可直接离线打开。

- A：使用构建时的 `src/tokens.css`、`src/App.css`、`src/capture-status.css`，当前基线为 `7825429`。
- B：相同组件叠加 `proposal.css`，改变分组、表面、文字层级和交互状态的视觉表达。
- C：相同组件叠加 `filled.css`，保留 A 的布局、字号与间距，移除容器描边，以灰绿页面底、白色卡片和浅绿实时记录区分层级。
- 时间线、月历、队列和录音状态复用真实 React 组件。三版共享内存中的示例状态。
- 日期、录制暂停、新建示例事件、详情/笔记、队列开关和重试可以操作。详情为简化的展示原型，未接入音频、真实后台或云 API。
- 人物库、设置保留导航位置，点击提示本次对比范围；这两页不在本次视觉原型内。
- 重试使用本地定时器演示待处理/处理中/完成。页面刷新或“重置预览”恢复初始示例。
- 默认打开 C，支持单版/三组并排比较、760/1120/1440 的逻辑窗口宽度、长文本及空状态。

在仓库根目录运行：

```sh
node playground/style-comparison/build.mjs
```

只生成 playground，不修改生产组件、不重启正在运行的 hear。若生产样式更新，重新构建会更新 A 的基线。
