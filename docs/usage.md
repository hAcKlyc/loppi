# 使用指南

loppi 在电脑可用且用户启用记录时，持续保存人声与时间线。安装与平台状态见 [README](../README.md#下载与安装)。云处理范围和数据位置见[隐私与数据](../PRIVACY.md)。

## 首次设置

1. 打开应用，选择麦克风、电脑声音或两者；按页面提示授予所选来源权限。
2. 等待本地组件检查成功。模型已经随安装包提供；检查失败时先重试，缺失或损坏则重新安装完整应用。
3. 配置 DeepSeek 和火山引擎 API Key。火山引擎需要开通录音文件识别标准版及对应权限；页面中的官方说明提供入口。
4. 完成设置，进入首页并主动开始记录。可以稍后设置并浏览首页，但首次录制仍受 Core 的就绪检查约束。

两项云服务需要自备账号，验证和实际使用可能产生费用。新截图原图也会按 LLM 配置进入云队列。开始使用前请阅读 [PRIVACY.md](../PRIVACY.md)。

## 日常记录与找回

时间线按日期浏览。命名事件表示系统或用户组织出的活动范围，未整理块仍可能包含可回放的人声、文字、笔记或截图。没有文字不代表没有录到声音，也不代表现实中没有说话。

打开详情可查看转写、来源、说话人和现场记录，点击时间定位回放。可以标记重点、添加评论或主动截图；人物名字和识别文字允许人工修正。需要时可手动精转一个范围，或从已有事件详情的「音频信息」重新精转。识别、人物匹配和 AI 整理结果都可能有误，重要内容请回听原声核对。

完整关键词检索可通过 CLI / MCP 的 Context 接口使用；图形界面不承诺单独的全文搜索页。接入方式见 [Agent Context](../specs/tech_docs/agent-context.md)。

## 智能标签与生成内容

在「智能分析 → 事件分析」定义标签与判断标准，在「语音识别·精转录」选择哪些事件精转，在「自定义策略」配置哪些标签触发生成。三个页签共享配置草稿，点击「保存配置」后生效。策略可以使用粗转稿或精转稿。只想手动执行时，将策略触发标签留空。

事件确定后按标签判断自动动作。详情可编辑标签并预览要补跑或撤掉的处理。事件确定后，从对应策略的标签页旁的 `+` 或更多菜单的「执行策略」手动选策略。缺少精转稿时可直接用粗转稿，也可先精转再生成。自动与手动结果都在事件的对应策略的标签页查看。

## 录音、队列与退出

录音和云处理分别控制。暂停云端整理或精转不会暂停已经启用的本地采集；恢复云队列会处理仍有效的积压任务。暂停录音也不会自动撤回已提交的云请求。

在「设置 → 录制 → 编辑计划」选择重复日期及开始、停止时间，默认七天全选。跨午夜归到开始日，例如只选周五时，周五 22:00 开始的计划在周六 06:00 停止。启用后，设置页会显示下一次定时动作。手动录制随时可用。

电脑睡眠、关机、未登录或完全退出时不承诺采集。锁屏但未睡眠时录音可能继续；Windows 锁屏时桌面截图不可用。登录启动和录制计划从设置中管理。关闭主窗口可能隐藏到菜单栏、系统托盘或悬浮入口；需要停止所有应用进程时使用应用的「退出」。

## 导出、清理与卸载

设置中的导出可以保存所选日期或范围的文字与音频，并选择是否包含截图。导出文件可能包含私人内容，请检查分享对象。

清理前阅读预览的时间、声音来源和数量。「清除原始音频」保留文字和已有声纹等派生信息；「清除全部数据」还会清理范围内的文字、现场记录与相关样例。它们都不会删除已另存的导出或供应商已经收到的输入。

默认卸载保留录音和数据库。整份数据的位置、备份要求及凭据移除方法见 [PRIVACY.md](../PRIVACY.md#存储与保护)。旧 hear 资料不会自动迁入 loppi，首次使用需要重新授权并配置凭据。

## 常见问题

**装好后是否能全程离线？** 本地人声检测和粗转使用随包模型。首次启用需要两项云服务配置；完成后，断网或暂停云队列不阻止已启用的本地采集，云结果稍后恢复处理。

**为什么没有生成事件或精转？** 检查本地组件、候选整理状态、两个云队列是否暂停、凭据和供应商账户是否可用。未整理不等于音频丢失，费用统计也不代表请求一定成功发布。

**为什么录音暂停？** 检查手动暂停、录制计划、权限、来源状态、容量上限和磁盘安全线。释放空间后按界面提示恢复，不依靠删除数据库绕过状态检查。

**如何报告问题？** 普通问题通过 [Issue](https://github.com/hAcKlyc/loppi/issues)提交版本、平台、复现步骤和脱敏结果。不要附真实谈话、数据库或凭据。安全问题请私密联系 [myagents.io@gmail.com](mailto:myagents.io@gmail.com)。
