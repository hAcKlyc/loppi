## 需求和历史记录

`specs/prd/` 保存需求契约、版本增量和开发台账，`specs/research/` 保存研究及验收记录，`plan.md` 保存最初 0.1 开发过程。历史文件中的 hear 名称、旧协议、旧模型、测试数量和安装状态属于当时版本，不自动成为当前用户说明。

阅读[最初产品 PRD](../specs/prd/prd_0.1.md)时先看顶部的当前适用范围，再结合后续版本 PRD；不要以历史“待公证”“模型需下载”或“尚无 Windows/MCP”推断当前状态。已发行功能以[版本说明](releases.md)与对应 Release 为准，当前源码以架构及代码为准，待验收功能以对应台账为准。

私有评测的原声、转录、数据库、供应商响应和外部来源工程不随本仓库发布。相关引用使用材料名说明，公开摘要提供方法、数量、模型身份和结果边界；本仓库不承诺仅靠摘要复现私人样本成绩。开发机绝对路径和机器标识在公开文本中作了规范化，不改变记录的运行结果；这不代表改写了 Git 历史。
