# loppi

loppi 是用户的日常声音与现场记录库：保存麦克风和电脑声音，整理事件与转录，关联评论、截图和人物，让以前的讨论、约定与细节可以找回并核对出处。

回顾某天、续接讨论、查原话与数字时使用它；用户要求管理记录时，也可控制录音与计划、保存标记/评论/截图、修订事件与文字、维护人物/声纹/词库、使用智能标签与事件策略、管理识别队列、导出和清理资料。具体操作按当前 CLI 指南发现。
