# 工作流

## 时段回顾

按日期用 digest 的默认 compact 模式浏览事件，每行查看标题、topics 和要点条数，按需展开 key_points、摘要和证据。必要时按日期浏览，围绕用户关心的事情整理活动、讨论和进展。摘要足够时不读全天原文；关键数字或歧义再核对。注明未采集和待处理范围。

## 讨论续接

用具体话题检索并展开相关事件。整理已明确的结论、仍待决定的问题，以及相较更早讨论的变化。根据材料决定哪些值得回答。涉及决定、承诺、数字时核对证据；区分原话、推断与建议，不把没有后续记录当成未执行。

## 说法核对

围绕用户提出的说法定位相关记录，读上下文而非只摘命中句。支持、矛盾、尚无足够材料分别表达。保留时间与 ref，不把候选方案写成已确定决定。

例：“昨天讨论的延期方案定了吗？”只讨论候选时回答“记录里讨论了方案，未显示最终决定”。
例：“今天大概忙什么？”事件卡片通常足够，按活动整理，不强制读完整日转录。
